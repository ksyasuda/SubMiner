Setup checklist
  1. Both machines need SSH key access: ssh-copy-id user@hostname (no password prompts).
  2. The remote machine just needs SubMiner installed. It is found automatically in its default install location (Windows), as SubMiner on the remote PATH, a macOS /Applications install, or the optional subminer command-line launcher. Windows remotes need the built-in OpenSSH Server enabled.
  3. Use Test connection to verify both. It checks SSH and finds SubMiner on the remote in one go.
